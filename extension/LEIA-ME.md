# Vale Copiloto (extensão do Chrome para o operador)

## Instalar (uma vez)
1. No Chrome, abra `chrome://extensions`.
2. Ligue **Modo do desenvolvedor** (canto superior direito).
3. Clique **Carregar sem compactação** e escolha a pasta `Documentos\vale\extension`.
4. Fixe o ícone "Vale Copiloto" na barra (ícone de quebra-cabeça → alfinete).
5. Clique no ícone, cole o **token do painel** (o mesmo do atalho "Vale painel", a parte depois de `token=`) e **Guardar**.

## Usar
- O ícone mostra quantos clientes **confirmaram** e precisam ser reservados já; chega também uma notificação.
- Abra a web de cita previa (link no ícone). O painel do Vale aparece no canto da página.
- Em cada tela: **Rellenar este paso** → o Vale preenche província, trâmite, dados ou contato do cliente
  e destaca o botão da web que você deve apertar. Você aperta.
- Se aparecerem vagas: **Proponer: dia hora** → o cliente recebe no WhatsApp/chat para confirmar.
- Se não houver vagas: **Sin huecos** → anota para todos os clientes desse trâmite (o Vale aprende as melhores horas).
- Cliente confirmou: escolha o cliente "RESERVAR YA", vá até a lista de vagas, **Marcar el hueco confirmado**,
  confirme na web; na página do justificante o código já vem preenchido → **Reservado ✓**.
  O cliente recebe o comprovante e o lembrete da véspera automaticamente.

O copiloto nunca aperta os botões da web sozinho e nunca reserva sem o "sim" do cliente.
Funciona só neste computador, com o Vale ligado.
